# Ushtro Senzorët

Faqe mësimi në shqip për testin e Senzorëve dhe elektronikës, Shtator 2026.

- 13 detyra dhe 99 hapa të shpjeguar.
- Pyetja origjinale pranë zgjidhjes.
- Shpjegim për çdo hap dhe mënyrë rikujtimi.
- Punon pa internet dhe pa instalime.

Hape `index.html` ose `Ushtro-Senzoret.html` në shfletues.

Për ta rindërtuar nga burimi, me Node.js:

```sh
node build-study.cjs
```

Ndrysho `compact.css` për pamjen, `compact-runtime.js` për ndërveprimin dhe
`professor-lessons.cjs` për shpjegimet. Faqet dhe pyetjet e dokumentit janë
të përfshira si pamje. Shënimet e administrimit të provimit nuk publikohen.

Gabimi i identifikuar në zgjidhjen e detyrës 10 shënohet veçmas.
